## 🎨 CÁC THÀNH PHẦN CẦN CẬP NHẬT

### 1. Tables (Index pages)

- Thêm `overflow-x-auto` container
- Thêm `min-w-[600px]` cho table
- Responsive padding: `px-3 lg:px-6 py-3 lg:py-4`

### 2. Forms (Create/Edit pages)

- Grid responsive: `grid-cols-1 lg:grid-cols-2`
- Input padding: `px-3 lg:px-4 py-2 lg:py-2.5`
- Button full-width mobile: `w-full sm:w-auto`

### 3. Cards/Stats (Dashboard)

- Grid responsive: `grid-cols-1 sm:grid-cols-2 lg:grid-cols-4`
- Padding responsive: `p-4 lg:p-6`

### 4. Modals

- Padding responsive: `p-4 lg:p-6`
- Buttons stack vertical mobile: `flex-col sm:flex-row`

### 5. Show/Detail pages

- Content padding: `p-4 lg:p-8`
- Grid responsive cho thông tin
